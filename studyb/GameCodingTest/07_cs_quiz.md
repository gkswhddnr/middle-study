# CS 객관식 25문제 (컴투스 8기 인턴 직격 대비)

컴투스 필기 = **객관식 ~20문제 + 코딩 3문제**. 객관식은 **CS 깊이보다 넓이**가 핵심.
운영체제 / 네트워크 / DB / 그래픽스 심화 / 알고리즘·자료구조 객관식 위주.

각 문제 1~2분. 본 문제집은 **개념 + 단답** 형식 (실제 시험과 동일).
