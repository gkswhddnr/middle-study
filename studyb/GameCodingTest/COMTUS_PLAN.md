- 점수 80% 이상이 안정권

## 직격 키워드 30개 — 시험 전날 마지막 점검

**OS:** 프로세스 vs 스레드, 데드락 4조건, Mutex/Semaphore, 페이지 폴트, 컨텍스트 스위칭

**네트워크:** TCP vs UDP, 3-way handshake, OSI 7계층, HTTP 상태코드, REST stateless

**DB:** ACID, 정규화 (1NF/2NF/3NF), 인덱스 장단점, JOIN 종류

**그래픽스:** Phong (Ambient/Diffuse/Specular), 반사벡터 `R = I - 2(N·I)N`, Z-Fighting, MVP 행렬, 알파블렌딩 모드 3종, 짐벌락/쿼터니언

**알고리즘:** 정렬 6종 복잡도, Big-O 순서, 해시 충돌 해결, DP 메모이제이션

**디자인 패턴:** Singleton, Observer, State, Factory, Object Pool, Strategy, Command, Service Locator (8개)

**Unity 기본:** Update/FixedUpdate/LateUpdate, Coroutine, Time.deltaTime, GC 세대, GetComponent 캐싱
