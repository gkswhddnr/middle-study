GameCodingTest 폴더에서 문제 하나 출제.

영역: $ARGUMENTS

**영역 매핑:**
- 비어있음 / "랜덤" → 모든 카테고리 랜덤
- "쉬운" / "기초" / "easy" / "초급" → 01_basic.md B1~B60 랜덤
- "워밍업" / "warmup" → B21~B60 (5~10분짜리)
- "중급" / "mid" → 02_intermediate.md M1~M10
- "고급" / "hard" → 03_advanced.md A1~A10
- "그래픽스" / "그래픽" / "gfx" → 04_graphics.md G1~G8
- "모바일" / "최적화" / "mobile" → 05_mobile_optimization.md O1~O8
- "회사" / "company" → 06_company_style.md C1~C12
- 회사명 (카카오/넥슨/크래프톤/데브시스터즈 등) → 그 회사 라벨 문제

**규칙:**
1. solutions/ 폴더 절대 열지 말 것 — 정답 노출 금지
2. 문제 본문 + 함수 시그니처 + 입출력 예시만 그대로 보여주기
3. 출제한 문제 번호는 대화 컨텍스트에 기억해두기 (사용자가 나중에 "채점해줘" / "힌트" 라고 자연어로 말할 때 참조용)
4. 끝에 안내: "다 풀면 코드 붙여서 보내주고, 막히면 '힌트' 한마디만"

**출제 형식:**

```
📝 [번호] [제목]

[문제 본문]

```csharp
[함수 시그니처]
```

다 풀면 코드 붙여서 보내주세요. 막히면 "힌트".
```
